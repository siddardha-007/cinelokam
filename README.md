# CineLokam

> Spin the movie globe. Explore world cinema, one country at a time.

**Live Demo:** [cinelokam.vercel.app](https://cinelokam.vercel.app/)

---

### About

CineLokam is a personal passion project built out of a love for international cinema and clean, interactive interfaces. Instead of scrolling through endless algorithmic feeds, you can spin a 3D globe, pick any country, and discover its defining films and classics.

*(Lokam means "world" in Telugu — blending a love for global storytelling with a nod to home.)*

---

### Highlights

- **Interactive 3D Globe:** Smooth, mobile-first country exploration built with WebGL.
- **Curated by Origin:** Instant access to top classics and notable films for each country.
- **Fast Search:** Jump directly to any country on the globe.
- **Lightweight Data Pipeline:** Pre-processed two-tier JSON architecture for fast loading and 60 FPS interaction.

---

### Built With

- **Frontend:** React, Vite, `react-globe.gl`
- **Data Pipeline:** Python
- **Deployment:** Vercel
